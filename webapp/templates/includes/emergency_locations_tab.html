Emergency Locations

Bulk audit, create, update and delete account Emergency Response Locations (E911 addresses). One row per location; set the Action column to NEW, MODIFY or DELETE.

1. Audit

  1. Click Fetch Locations to load every emergency location.
  2. Click Download .xlsx for the full list. Address fields are exported exactly as RingCentral returns them (columns differ by country).

2. Create / Update / Delete

  1. Edit the sheet. Set Action to MODIFY, NEW or DELETE.
  2. For NEW, clear LocationId, set Name, SiteId, AddressFormatId and the Address.* fields.
  3. Friendly values are accepted. You can enter Country/Address.state/Address.streetType by name (e.g. "Australia", "Queensland", "Drive") — the tool resolves them to RC codes, auto-selects the country's address format, fills stateId, and validates the row before sending (a bad street type, zip, or missing required field is rejected up front with a clear message, instead of RC silently dropping it).
  4. Upload, pick the Sheet, and click Apply Changes.

➕ New location template

Pick a country and download a ready-to-fill sheet with the correct columns for that country's address format, the format id pre-set, an example row, and a Reference tab listing valid states and street types. Enter friendly names (e.g. "Queensland", "Drive") — the tool resolves them on upload.

🐞 Debug — get raw location JSON

Inspect the untouched RingCentral response. Leave the ID blank to sample the first few locations on the account, or paste a specific LocationId. Use this to capture the non-US / international address shape.
