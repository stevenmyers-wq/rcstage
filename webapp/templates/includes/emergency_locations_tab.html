Emergency Locations

Bulk audit, create, update and delete account Emergency Response Locations (E911 addresses). One row per location; set the Action column to NEW, MODIFY or DELETE.

1. Audit

  1. Click Fetch Locations to load every emergency location.
  2. Click Download .xlsx for the full list. Address fields are exported exactly as RingCentral returns them (columns differ by country).

2. Create / Update / Delete

  1. Edit the sheet. Set Action to MODIFY, NEW or DELETE.
  2. For NEW, clear LocationId, set Name, SiteId, AddressFormatId and the Address.* fields.
  3. Non-US: AddressFormatId is country-specific (e.g. US 19, AU 33, NZ 174) — the easiest path is to copy a row from an existing location in that country. Use Get raw example if unsure.
  4. Upload, pick the Sheet, and click Apply Changes.
