Extension Uploader

Bulk-create extensions from a simple template — Site Name, Extension, First Name, Last Name, Email, User Type, Department, Role, Notification Email. Site and Role dropdowns are polled from the connected account. Email is the extension's contact email; Notification Email (optional) is where voicemail/missed-call notices go, can differ, and is applied right after the extension is created. Nothing is created until you review the proposed changes; any email or extension already in use is flagged first.

Diagnostics

Shows the account's extension-number limits and the numbers RingCentral will actually let you assign per type. Use this to see why a specific number is rejected (EXT-250).

1. Download Template

A blank Extension Upload sheet with dropdowns for Site Name, User Type and Role, filled from this account. For Message Only, Announcement Only and Limited Extension only the First Name is used.

2. Upload & Review

Upload your completed sheet. Nothing is created yet — every row is validated against the live account so you can review the new extensions. Emails or extensions already in use are flagged, and each extension number is checked with RingCentral (via free-numbers & validate) so an unassignable number is caught here, not on Create.
