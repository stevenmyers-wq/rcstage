Caller ID

Set the outbound caller ID (CLI) for your users. Pick users in-tool and apply one number to all of them, or download the spreadsheet, edit the New Caller ID column and upload it back. The chosen number is written to each user's calling features (RingOut, the mobile app, call log and more); features left blocked or on current location aren't touched.
