Extension Activation

Bulk-change the activation status of the connected account's extensions — for example, take users from Not Activated to Enabled, switch an extension off with Disabled, or send one back to Not Activated. Load every extension below, narrow with the Type, Site and Status filters, tick the ones to change, pick the target status and click Apply.

1. Select Extensions

Load the account, then tick the extensions to change.

2. Set Activation Status

Choose the status to apply to every ticked extension. Enabled activates the extension (this is what takes a Not Activated user live); Disabled switches it off while keeping it assigned; Not Activated returns it to the un-activated state. RingCentral decides which transitions are allowed for each extension type — any rejection is reported per-extension in the log below.

Or: Bulk Update from a Spreadsheet

Prefer a spreadsheet? Download a template pre-filled with every extension and its current status, set the desired status per row from the dropdown, then upload to review and apply. Rows are matched by the friendly Extension number (the stable Extension ID is carried along for exact matching).

1. Download Template

An Extension Activation sheet pre-filled with every extension and its Current Status. Edit the New Status column (an Enabled / Disabled / NotActivated dropdown); the optional Suspension Reason & Comment apply only when disabling. Rows left unchanged are skipped.

2. Upload & Review

Upload your edited sheet. Nothing changes yet — every row is matched to a live extension (by Extension ID, then Extension number) so you can review the exact status changes before applying them.
