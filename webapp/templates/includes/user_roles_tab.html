User Roles

Audit, create and update custom user roles as a permission matrix. One row per role, one column per assignable permission (X = granted).

1. Audit

  1. Click Fetch Roles to load every role and its permissions.
  2. Click Download .xlsx for the full permission matrix.

2. Create / Update

  1. Edit the matrix. Set the Action column to MODIFY (edit an existing role) or NEW (create one).
  2. Toggle permissions with X (blank = not granted). For NEW, clear RoleID and set DisplayName + Scope.
  3. Upload the file, pick the Sheet to read, and click Apply Changes. Predefined roles are read-only and are skipped.
